# Competitive landscape snapshot

Snapshot date: 2026-10-03. This file exists to prevent the project from drifting into already-crowded categories. Re-check before making product-positioning claims.

## Do not become another generic coding agent

Claude Code, Codex, Pi, OpenCode, Cursor and other coding agents already own code-generation/execution workflows. WitDiff should integrate with them.

## Adjacent open-source projects found during initial research

- **PatchProof** — base/head regression-test proof for several test ecosystems. Closest conceptual neighbor to the initial red/green proof.
- **irradiate** — Rust-written changed-code mutation testing focused on Python.
- **Tautest** — changed-line mutation/test quality gating, strongest in JS/TS.
- **agent-verify** — verifies factual completion claims made by coding agents.
- **backcheck** — audits coding-agent transcripts/claims against tool evidence.

## Differentiation target

WitDiff should converge on a broader, vendor-neutral concept of **executable proof receipts for AI-written code**, combining:

1. controlled base/head experiments;
2. test-integrity checks;
3. evidence freshness;
4. changed-code mutation proof;
5. later cross-language adapters;
6. stable machine-readable receipts that any agent can consume.

Do not claim “no competitors.” Compete by making evidence semantics stronger, conservative, cross-language, local-first, and easy for every coding agent to invoke.
